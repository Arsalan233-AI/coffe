# Brew & Bloom Coffee Café

A responsive, single-page website for a coffee café.

## Pages / Sections

| Section | Description |
|---|---|
| **Hero** | Full-screen banner with call-to-action buttons |
| **About** | Story, stats (origins, daily cups, years open) |
| **Menu** | Filterable cards – Hot Drinks, Cold Drinks, Food |
| **Specials** | Today's seasonal highlights |
| **Testimonials** | Customer reviews |
| **Contact** | Address, hours, phone, email + contact form |

## Files

```
index.html   – HTML structure
styles.css   – All styling (CSS custom properties, responsive)
script.js    – Navbar scroll/highlight, mobile menu, menu tabs, contact form
```

## Running locally

```bash
# Any static file server works, e.g.:
python3 -m http.server 8080
```

Then open `http://localhost:8080` in your browser.
